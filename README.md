 FNB Superhero App

Overview

The FNB Superhero App is a beginner-level web application created as part of the FNB App Academy  
This project focuses on building a static user interface while learning how to structure and style a web application using core web technologies.

It represents one of my early projects and highlights my growth in front-end development fundamentals.

Purpose of the Project

The goal of this project was to:
- Learn how to structure a web page using HTML
- Apply styling and layout techniques using CSS
- Understand how real-world apps are visually designed
- Build confidence in creating and publishing projects on GitHub

Languages Used
- HTML – page structure and content  
- CSS – styling, layout, and responsiveness  

Features
- Static user interface inspired by the FNB Superhero concept
- Clean and simple layout
- Custom styling using CSS
- Beginner friendly and readable code
